# Site-do-cinema
Site fictício de venda de ingressos para um cinema particular em casa. Um projeto desenvolvido para simular a experiência de compra de ingressos para uma sessão exclusiva, unindo tecnologia, criatividade e romantismo em uma noite especial.

# Técnologias utilizadas

 - HTML5
 - CSS3
 - JavaScript
 - GitHub

# Porque considero importante?
fazendo um projeto simples desse utilizando HTML, CSS, JS e GitHub, aprimoro meus conhecimentos na área e nas ferramentas utilizadas. sem contar que utilizo estrutura básica de um site, estilização e funcionamento.
